# 발표 PPT 디자인 시스템

getdesign.md의 Claude DESIGN.md(크림 · 코랄 · 다크 네이비, 세리프 제목)를 **16:9 PowerPoint 슬라이드**에 맞게 옮긴 규칙입니다.

- 웹 단위(px)를 PPT 단위(pt, cm)로 바꿨습니다.
- 한글 글꼴을 짝지었습니다.
- 프로젝터에서 읽히도록 **대비(WCAG)를 계산해서** 색마다 쓸 수 있는 곳을 정했습니다.

> **브랜드 주의**: 이 문서는 색 · 글꼴 · 간격의 *분위기*만 빌려 옵니다. Anthropic 스파이크 마크(별 모양 로고), "Claude" 워드마크, Copernicus · StyreneB(라이선스 글꼴)는 쓰지 않습니다. 원문도 공식 디자인 시스템이 아니라 공개 사이트를 보고 정리한 참고 자료입니다.

## 2. 글꼴

원문의 "세리프 제목 + 휴머니스트 산세리프 본문 + 고정폭 코드" 구성을 무료 글꼴로 맞춥니다.

| 역할 | 원문 | PPT (한글 포함) | 없을 때 |
|---|---|---|---|
| 제목 (세리프) | Copernicus 400 | **마루부리** (네이버, 무료) 또는 **Noto Serif KR** | 바탕 |
| 본문 · 표 · 라벨 | StyreneB / Inter | **Pretendard** | 맑은 고딕 |
| 코드 · 터미널 | JetBrains Mono | **JetBrains Mono** (영문) + **D2Coding** (한글) | Consolas |

- PowerPoint 테마 글꼴(디자인 › 변형 › 글꼴 › 글꼴 사용자 지정): 제목 = 마루부리, 본문 = Pretendard (한글 · 영문 둘 다 같은 글꼴로 지정)
- **제목은 굵게 하지 않는다.** 원문 원칙 "세리프는 400" → 마루부리 Regular 또는 SemiBold까지. 강조가 필요하면 굵기 대신 크기를 키운다.
- 발표 PC에 글꼴이 없으면 대체 글꼴로 바뀐다. 파일 › 옵션 › 저장 › **파일의 글꼴 포함**을 켜거나, 발표 PC에 미리 설치한다.

### 2-1. 글자 크기 (슬라이드용)

웹 크기를 그대로 옮기면 뒷자리에서 안 보여서, 역할은 원문을 따르고 크기는 발표용으로 정했습니다.

| 토큰 | 원문 | PPT 크기 | 글꼴 · 굵기 | 자간 | 줄 간격 | 쓰는 곳 |
|---|---|---|---|---|---|---|
| `display-xl` | 64px | **54pt** | 마루부리 400 | −2% | 1.05 | 표지 제목 |
| `display-lg` | 48px | **40pt** | 마루부리 400 | −1.5% | 1.1 | 섹션 구분 제목 |
| `display-md` | 36px | **32pt** | 마루부리 400 | −1% | 1.15 | 일반 슬라이드 제목 |
| `display-sm` | 28px | **28pt** | 마루부리 400 | −1% | 1.2 | 콜아웃 문장, 큰 숫자 |
| `title-md` | 18px | **22pt** | Pretendard 500 | 0 | 1.3 | 카드 제목, 리드 문장 |
| `body` | 16px | **20pt** | Pretendard 400 | 0 | 1.4 | 본문 (최소 18pt) |
| `table` | — | **16~18pt** | Pretendard 400 | 0 | 1.3 | 표 내용 |
| `caption` | 13px | **14pt** | Pretendard 500 | 0 | 1.3 | 출처, 화면 설명 |
| `eyebrow` | 12px 대문자 | **12pt** | Pretendard 500 | +10% | 1.0 | 섹션 라벨 (`01 · URL`) |
| `code` | 14px | **14~16pt** | JetBrains Mono / D2Coding 400 | 0 | 1.35 | 코드, 터미널, 요청 줄 |

- 한글은 영문보다 획이 많아서 **본문 줄 간격 1.4**를 기본으로 한다.
- PowerPoint 자간: 글꼴 › 문자 간격 › 좁게 0.5~1pt 정도가 −1~−2%에 해당한다.

## 3. 간격과 격자

### 3-1. 슬라이드 크기와 여백

- 크기: **와이드스크린 16:9 (33.867 × 19.05 cm)**
- 바깥 여백: 좌우 **1.8 cm**, 위 **1.4 cm**, 아래 **1.2 cm**
- 내용 폭: 30.27 cm → **12열 격자**, 열 사이 0.6 cm (1열 ≈ 1.97 cm)
- 원문 "최대 폭 1200px, 6/6 분할" → 슬라이드에서는 **6열 + 6열 (좌우 15.0 cm씩)**

### 3-2. 위치 고정값 (모든 일반 슬라이드 공통)

| 요소 | 위치 (위에서) | 비고 |
|---|---|---|
| eyebrow 섹션 라벨 | 1.4 cm | 12pt, muted, 대문자 영문 + 번호 |
| 제목 | 2.0 cm | 32pt 마루부리, 한 줄 원칙 |
| 내용 시작 | 4.4 cm | 제목과 내용 사이 여백은 늘 같게 |
| 쪽 번호 | 아래 1.0 cm, 오른쪽 정렬 | 11pt, muted-soft |

### 3-3. 간격 단위 (4px → 0.2 cm 기준)

## 4. 깊이

원문 원칙: **색 면으로 깊이를 주고, 그림자는 거의 쓰지 않는다.**

- 그림자 **끔** (도형 서식 › 효과 › 그림자 없음). PowerPoint 기본 도형은 그림자 · 테두리가 붙으니 매번 끈다.
- 그라데이션 · 3D · 네온 · 반사 효과 **쓰지 않음**.
- 깊이는 세 가지로만 만든다.
  1. 바탕 `canvas`
  2. 한 단계 진한 `surface-card`
  3. 대비가 큰 `surface-dark`

## 7. 해야 할 것 · 하지 말 것

**할 것**
- 모든 일반 슬라이드는 크림(`#FAF9F5`) 바탕. 순백 금지.
- 제목은 세리프(마루부리), 본문은 Pretendard. 이 둘을 섞지 않는다.
- 코랄은 **슬라이드당 한 곳**만. 넓게 쓸 때는 콜아웃 띠로, 섹션당 한 번.
- 코드 · 응답 · 문서는 **실제 화면**을 다크 카드나 스크린샷으로 보여 준다. 그려서 흉내 내지 않는다.
- 섹션 경계에 다크 슬라이드를 넣어 리듬을 만든다.
- 강조는 굵기보다 크기로.

**하지 말 것**
- 세리프 제목을 굵게(700) 하지 않는다.
- 파랑 · 청록을 강조색으로 쓰지 않는다. 청록은 다크 코드 안에서만.
- 초록 · 청록 글자를 크림 바탕에 올리지 않는다 (대비 2.2~2.3).
- 코랄 글자를 24pt 미만으로 크림 위에 쓰지 않는다. 작은 코랄 글자는 `primary-active`.
- 같은 바탕의 섹션 구분을 두 번 연속 넣지 않는다.
- 그림자 · 그라데이션 · 아이콘 남발 · 로고 · 스파이크 마크를 쓰지 않는다.

## 8. PowerPoint에서 바로 설정하기

1. **디자인 › 슬라이드 크기 › 와이드스크린(16:9)**
